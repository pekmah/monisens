# ExecPlans

This folder stores Monisens execution plans, called ExecPlans. Follow the root `PLANS.md` exactly.

Use `TEMPLATE.md` to start new plans. Name plan files with a date and short slug so they sort naturally, for example:

    docs/ai/plans/2026-05-18-transaction-filter-refresh.md
    docs/ai/plans/2026-05-18-backup-portability.md

Keep plans in this folder even after completion. Completed plans are useful implementation records because they include decisions, surprises, validation evidence, and retrospective notes.

Do not store secrets, tokens, private keys, or full production environment files in plans. If production commands or logs are relevant, include only the safe excerpts needed to prove behavior.
